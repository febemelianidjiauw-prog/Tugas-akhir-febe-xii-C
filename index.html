Apa yang akan kita pelajari?

Melalui kegiatan ini, kamu akan diajak mengenal dunia pemrograman dan teknologi digital dari tingkat paling dasar. Kami menghadirkan suasana belajar yang seru untuk melatih logika berpikir serta daya kreativitasmu dalam merancang sebuah situs web dari nol hingga menjadi tampilan yang utuh, nyaman diakses di berbagai perangkat, dan menarik.

Program ini disusun khusus untuk pemula. Berikut adalah pokok bahasannya:

  • HTML (Hypertext Markup Language): Berlatih menyusun kerangka dan fondasi dasar halaman web, mulai dari menata teks, menyisipkan gambar, membuat tabel, hingga formulir input.
  • CSS (Cascading Style Sheets): Mempercantik tampilan visual situs agar enak dipandang. Kita akan mempraktikkan pemilihan warna, jenis huruf, tata letak (layouting), serta tampilan yang menyesuaikan layar HP maupun laptop.
  • JS (JavaScript): Memberikan efek interaktif pada halaman web. JavaScript dipakai untuk menciptakan animasi sederhana, kotak pesan pop-up, aplikasi kalkulator mini, dan fitur dinamis lainnya.
  • Dasar Logika Python (Pilihan Tambahan): Mempelajari konsep awal algoritma pemecahan masalah (problem solving) memakai bahasa Python yang ringkas dan mudah dipahami pemula.
